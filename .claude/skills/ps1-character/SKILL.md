# PS1-персонаж: рабочий процесс

1. Читай `CLAUDE.md` и `viewer/tools/make_human.py` — персонаж собирается этим скриптом из CC0-модели Quaternius.
2. Одежда/цвета: таблица `RECOLOR` (цвет полос исходной текстуры → новый) и маска сапог по высоте в материале запекания.
   Шум/грязь: ноды Noise в материале запекания; AO смешивается в конце. Размер текстуры — `TEX` (128).
3. Другая готовая модель: только **CC0** (Quaternius на opengameart.org качается curl'ом; Kenney). Поменяй `URL`, путь к .blend/.fbx
   и имена объектов в скрипте, запиши источник в `viewer/models/CREDITS.md`.
4. Пересобери: `pip install bpy numpy pillow && python3 viewer/tools/make_human.py`.
5. Проверь глазами: `python3 -m http.server` в `viewer/`, Playwright-скриншоты (десктоп + мобильный 400×800, лицо крупно, пара анимаций).
   Сравни с референсом пользователя: тёмное фэнтези, грязные пиксельные текстуры, туман, тёплый фонарь.
6. Коммить `viewer/models/human.glb` вместе со скриптом, пуш в `main`, дождись Pages и проверь `https://nvwrist.github.io/viewer/`.

Типовые дефекты: выцветшие цвета = двойная гамма (байтовые картинки Blender уже sRGB); «плоские» цвета = не запёкся шум;
модель не та во вьюере = кэш Pages (index.html грузит `main.js?t=`).
