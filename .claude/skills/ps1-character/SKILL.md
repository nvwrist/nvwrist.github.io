# PS1-персонаж: рабочий процесс

1. Читай `CLAUDE.md` (структура, грабли) и `viewer/tools/make_character.py` — вся модель описана кодом.
2. Редактируй генератор, не `.glb` руками. Части добавляются как `Part(V, F, C, bone=..., mat=..., name=...)`:
   - `tube(P, R, ...)` — труба по ломаной с эллиптическим сечением (конечности, торс, волосы);
   - `ellipsoid(...)` — сферы/головы (деформируй по направлению `u`); `box(...)` — блоки (пряжки, кобура).
   - `mat=1` — светящийся (cyan emission) материал; остальное — вершинные цвета × атлас.
3. Пересобери: `python3 viewer/tools/make_character.py` (нужен `pip install bpy numpy pillow`).
4. Проверь глазами: подними `python3 -m http.server` в `viewer/`, сними Playwright-скриншоты спереди/сзади/крупно лицо и по одной позе из каждого клипа. Сравни с референсом пользователя: длинные тёмные волосы, тёмные очки, чёрная майка с красной эмблемой, белая кибер-рука, ботинки, неон.
5. Типовые дефекты: белые пятна = UV вышли за прямоугольник атласа; «резинка» при позе = не тот белый список костей; чёрные пятна = вершинные цвета не экспортированы (`export_vertex_color='ACTIVE'`).
6. Коммить `viewer/models/neon-runner.glb` вместе со скриптом. Пуш в `main`.

Стиль: угловатость допустима, но силуэт должен читаться (плечи, волосы, рука, ботинки); детали — через цвет вершин и маленький атлас, а не через тысячи полигонов.
